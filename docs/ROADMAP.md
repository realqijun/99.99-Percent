# Roadmap

99.99 Percent is being rebuilt as a turn-based card game for itch.io.
It runs offline in the browser and saves to localStorage.
Work happens on the `rewrite/cards` branch, which merges to `main` once a full run can be played.

The full rules are in [GAMEPLAY.md](GAMEPLAY.md).

1. Strip the old game and set up the itch.io build. Done.
2. The engine contract: shared types, the engine API and the module layout. Done.
3. In parallel: the engine, the content, the UI and store, the pixel art, and the audio. Done.
4. Integrate them, tune difficulty with a bot, write the browser tests, and make the itch.io page assets. Done.
5. Merge to `main`, upload to a draft itch.io page, and playtest it in Chrome, Firefox and Safari.

The course-era roadmap, proposal and phase plans are in [PROJECT_PROPOSAL.md](PROJECT_PROPOSAL.md), [phases/](phases/) and Git history.
